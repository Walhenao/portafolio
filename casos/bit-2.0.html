BIT 2.0 — Biblioteca Integrada de Trabajo

Plataforma SGI / Agente de Monitoreo: documentos controlados, automatización de procesos, indicadores, SAM, actas e IA.

Automatiza el ciclo del SGI para reducir tiempos: carga documental, monitoreo, actas y evidencia con IA.

En palabras fáciles

BIT ordena documentos oficiales, sigue indicadores/riesgos/acciones de mejora y ayuda a generar actas. También puede convertir audio de reuniones en texto útil.

Automatizaciones que importan

  • Upload → validación → storage versionado → preview Office→PDF
  • Cambios masivos con lotes, tareas asíncronas y scheduler
  • Indicadores, riesgos y SAM por proceso
  • Generación de actas institucionales
  • MITRA: Faster-Whisper para transcripción y apoyo a actas

Lado técnico

FrontendNext.js 14, TypeScript, Tailwind, React Query
BackendPython 3.11, FastAPI, SQLAlchemy, Pydantic v2
JobsTareas asíncronas + APScheduler
IAFaster-Whisper (ctranslate2)
AuthJWT, 2FA, SSO institucional

Valor

Menos tiempo buscando documentos, actualizando plantillas o armando actas; más trazabilidad para decidir.
