# 2. CNN — Detección de glioma en MRI

**Curso:** Técnicas de Deep Learning · Uniandes  
**Nivel:** Destacado (muy llamativo)

---

## En palabras fáciles — ¿para qué sirve?

Una resonancia magnética del cerebro es una imagen compleja. Este proyecto entrena una red para **detectar si hay señales compatibles con glioma** (un tipo de tumor).

**Importante:** no reemplaza al médico. Sirve como **apoyo automático** para revisar imágenes más rápido y con un criterio consistente.

**Sirve para:** entender IA en salud, visión por computador y sistemas de apoyo a decisión con evidencia visual.

---

## Qué problema resuelve

Revisar muchas imágenes a mano toma tiempo y es fácil cansarse. Un modelo puede dar una **primera lectura** (posible glioma / no glioma) para priorizar atención.

---

## Lado técnico

| Elemento | Detalle |
|----------|---------|
| Tarea | Clasificación binaria en MRI 2D |
| Clase positiva | Glioma |
| Clases negativas | Meningioma, pituitary, healthy (agrupadas como no glioma) |
| Arquitectura | CNN + transferencia de aprendizaje (redes residuales / pretrained) |
| Dominio | Imágenes médicas |
