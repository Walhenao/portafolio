# 5. ML supervisado — Predicción de hipertensión

**Curso:** Principios / ML supervisado · Uniandes  
**Nivel:** Capacidad ampliada

---

## En palabras fáciles — ¿para qué sirve?

Con datos de personas (edad, sueño, estrés, colesterol, etc.) el modelo aprende a estimar si alguien tiene **más probabilidad de hipertensión**.

Es un ejemplo claro de: “miro variables → aprendo de casos pasados → ayudo a anticipar un riesgo”.

**Sirve para:** decisión basada en evidencia, salud preventiva y explicar ML supervisado a no técnicos.

---

## Qué problema resuelve

Sin un modelo, es difícil combinar muchas variables a la vez. El aprendizaje supervisado encuentra patrones útiles para **clasificar riesgo** de forma repetible.

---

## Lado técnico

| Elemento | Detalle |
|----------|---------|
| Tarea | Clasificación supervisada |
| Target | `Hipertension` (sí/no) |
| Features | Edad, sal, estrés, colesterol, sueño, BMI, medicación, historia familiar, actividad, fumador, glucosa, enfermedad coronaria, etc. |
| Flujo | EDA → limpieza → variables → entrenamiento → métricas (accuracy / precision / recall / F1 según balance) |
| Enfoque | Dataset tabular clásico de ML |
