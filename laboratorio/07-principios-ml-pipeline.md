# 7. Principios de ML — Pipeline de extremo a extremo

**Curso:** Principios de Machine Learning · Uniandes  
**Nivel:** Capacidad ampliada (rigor metodológico)

---

## En palabras fáciles — ¿para qué sirve?

Este no es “un modelo suelto”. Es el **método completo** para hacer bien un proyecto de ML:

entender los datos → limpiarlos → elegir variables → entrenar → evaluar → interpretar.

Es la “receta profesional” para que un modelo sea confiable, no improvisado.

**Sirve para:** demostrar madurez: sabes el proceso, no solo apretar “Run”.

---

## Qué problema resuelve

Muchos demos fallan en la vida real porque saltan pasos (datos mal entendidos, métricas equivocadas, fugas de información).  
Este trabajo muestra disciplina de **pipeline**.

---

## Lado técnico

| Elemento | Detalle |
|----------|---------|
| Etapa 1 | Exploración, diccionario de datos, calidad, hipótesis |
| Etapa 2 | Modelado supervisado sobre caso aplicado (hipertensión / datos tabulares) |
| Prácticas | EDA, tratamiento de variables, balance de clases, métricas adecuadas |
| Entregables | Notebooks + reportes HTML/PDF de proceso |
| Énfasis | Trazabilidad del análisis y decisiones metodológicas |
